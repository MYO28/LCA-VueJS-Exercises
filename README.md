# FlexZone Fitness - Class Scheduler (Lite)

A responsive single-page web application built with Vue.js to help gym staff manage group workout sessions efficiently.

## Project Overview

**FlexZone Fitness** needed a solution to digitize their manual scheduling process. This application serves as a prototype for staff to create, view, and manage fitness class sessions (e.g., Yoga, Pilates, Strength Training).

This project focuses on clean component architecture, form validation, and reactive data handling. It is designed to be user-friendly, responsive, and functional without the need for a backend database.

## Key Features

- **Add Class Form:** Allows staff to input class details (Name, Coach, Date, Time, Capacity) with real-time validation.
- **Dynamic Schedule:** A real-time updating list of all scheduled sessions.
- **Management Tools:** Easy deletion of classes when cancellations occur.
- **Responsive Design:** Optimized for both desktop and mobile viewing.
- **Interactive Feedback:** Friendly UI states, including "No sessions scheduled" for empty states.
- **Reactive Totals:** Automatically calculates the total number of scheduled sessions.
