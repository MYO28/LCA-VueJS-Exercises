# Cooking Masterclass Catalogue

### 1. Project Overview

This is an interactive single-page web application prototype built using Vue 3 and Vite. It allows users to explore available cooking workshops, view details such as chef names, pricing, and skill levels, see real-time "Sold Out" availability states, and dynamically add or remove items from a wishlist counter.

### 2. Key Features Implemented

- Dynamic rendering of course cards (no hard-coded duplicates)
- Real-time wishlist counting in the header using Vue events
- "Sold Out" state tracking and button disabling
- Responsive layout (Mobile & Desktop) via Bootstrap 5
- Live class filtering by difficulty level and availability _(Stretch Goal)_
- Localized price formatting using ZAR currency _(Stretch Goal)_
